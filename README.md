# Nighttime Lights in Conflict
Data and code for our work on assessing the use of nighttime lights as a tool to measure conflict in Yemen and Ukraine.

Working paper title:
**Nighttime lights as a viable tool for measuring conflict in Yemen and Ukraine**

Maia C. Tarnas<sup>1*</sup>, Tetyana I. Vasylyeva<sup>1,2</sup>, Volodymyr M. Minin<sup>3</sup>, Daniel M. Parker<sup>1,2</sup>

1. Department of Population Health & Disease Prevention, University of California, Irvine
2. Department of Epidemiology and Biostatistics, University of California, Irvine
3. Department of Statistics, University of California, Irvine

* Corresponding author: mtarnas@uci.edu

## Information on Data ##
This study uses data collected from several sources.

Nighttime lights: [NASA Black Marble](https://blackmarble.gsfc.nasa.gov/), extracted using [*blackmarbleR*](https://worldbank.github.io/blackmarbler/) package

Attacks: [Yemen Data Project](https://yemendataproject.org/) (Yemen) and [Armed Conflict Location and Event Data](https://acleddata.com/) (Ukraine)

Population: [WorldPop](https://www.worldpop.org/)

Built environment: [Sentinel-2 Dynamic World](https://developers.google.com/earth-engine/datasets/catalog/GOOGLE_DYNAMICWORLD_V1), extracted using Google Earth Engine

Diesel: World Food Programme via [Humanitarian Data Exchange](https://data.humdata.org/dataset/wfp-food-prices-for-yemen)

Data used in the cholera case study can be found in the [original paper's GitHub](https://github.com/parker-group/airraids-Yemen-LancetGH)
